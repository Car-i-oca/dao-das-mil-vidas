# Nomes para o novo jogo (v2)

O novo jogo precisa de um nome próprio para o APK de teste (para poder ficar instalado ao lado do atual) e, depois da aprovação, para a versão final. Escolha um (ou misture) e eu aplico em: nome do app, `appId`, manifesto do PWA, título da página, tela inicial, README e rodapé.

**Como pesquisei:** busquei cada nome na web (jogos, apps do Google Play, sites). **Nenhum apareceu como jogo ou app com o mesmo título.** É uma busca rápida, **não é consulta de marca**: se escolher um, faço a mesma pesquisa de `docs/marca.md` (inclusive a base do INPI, que o autor consulta) antes de publicar para o público.

## Minhas indicações
1. **Fios do Dao**: é o mais curto, descreve o sistema novo (fios abertos, consequências) e cabe bem como nome de ícone.
2. **Crônicas do Dao**: o mais claro para quem não conhece o jogo e combina com o critério de qualidade (ler a vida como crônica).
3. **O Livro dos Que Ficaram**: o mais autoral, para um jogo cujo coração é a memória do mundo.

Se quiser outras direções (mais sombria, mais chinesa, mais curta, ou em inglês), me diga o tom e gero outra lista.

## O que muda quando você escolher
- APK com nome e `appId` próprios (assim instala ao lado de "Dao das Mil Vidas" sem sobrescrever).
- Site da versão de teste em `/v2/` com save separado (`dao-mil-vidas-save-v2`).
