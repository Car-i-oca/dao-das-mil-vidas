# Direção de Murim Quest

Murim Quest é um projeto pessoal de Andre Barbosa Vieira. É um RPG narrativo para celular, em português brasileiro, sobre escolas marciais e vidas no Jianghu.

## Princípios atuais

- A campanha ativa tem personagens, escolas, conflitos e escolhas próprios do cenário Murim.
- A estrutura de evento, decisão, teste e consequência guia o ritmo da partida.
- Alinhamento de caminho e moralidade são variáveis distintas.
- O jogador deve entender o risco dos testes, o efeito dos itens e por que uma opção apareceu.
- O progresso de uma vida deve continuar entre cenas e influenciar o legado final.
- A interface prioriza leitura, alvos de toque e limites de tela móvel.
- Compatibilidade de saves deve ser mantida quando uma atualização altera apenas regras ou apresentação; mudanças incompatíveis precisam de migração explícita.

## Histórico

O projeto evoluiu de um jogo de cultivação genérico para uma campanha de Murim. Os documentos antigos de desenvolvimento e os catálogos xianxia foram removidos da documentação ativa. O histórico de commits preserva a evolução técnica do repositório.
